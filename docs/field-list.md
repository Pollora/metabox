# Field list

Every field of the package, with the Meta Box field type it creates and the page documenting it. The [common settings](common-settings.md) apply to all of them.

## Basic fields

| Field | Meta Box type | Description |
|---|---|---|
| [`Text`](basic-fields.md#text-field) | `text` | One-line text input. |
| [`Textarea`](basic-fields.md#textarea-field) | `textarea` | Multi-line text input. |
| [`Select`](basic-fields.md#select-field) | `select` | Dropdown list. |
| [`SelectTree`](basic-fields.md#selecttree-field) | `select_tree` | Hierarchical options, one select per level. |
| [`Checkbox`](basic-fields.md#checkbox-field) | `checkbox` | Single checkbox. |
| [`CheckboxList`](basic-fields.md#checkboxlist-field) | `checkbox_list` | List of checkboxes, flat or as a tree. |
| [`Radio`](basic-fields.md#radio-field) | `radio` | Radio buttons. |

## Advanced fields

| Field | Meta Box type | Description |
|---|---|---|
| [`Autocomplete`](advanced-fields.md#autocomplete-field) | `autocomplete` | Text input suggesting values from a list or an AJAX URL. |
| [`Background`](advanced-fields.md#background-field) | `background` | Background color, image, repeat, position and size. |
| [`BlockEditor`](advanced-fields.md#blockeditor-field) | `block_editor` | Content edited with the block editor. |
| [`Button`](advanced-fields.md#button-field) | `button` | Button triggering custom JavaScript. |
| [`ButtonGroup`](advanced-fields.md#buttongroup-field) | `button_group` | Options displayed as a group of buttons. |
| [`Color`](advanced-fields.md#color-field) | `color` | Color picker, with optional transparency. |
| [`CustomHtml`](advanced-fields.md#customhtml-field) | `custom_html` | Custom HTML, without a value. |
| [`Datepicker`](advanced-fields.md#datepicker-field) | `date` | Date picker. |
| [`DatetimePicker`](advanced-fields.md#datetimepicker-field) | `datetime` | Date and time picker. |
| [`FieldsetText`](advanced-fields.md#fieldsettext-field) | `fieldset_text` | Several text inputs saved together. |
| [`Hidden`](advanced-fields.md#hidden-field) | `hidden` | Hidden input. |
| [`ImageSelect`](advanced-fields.md#imageselect-field) | `image_select` | Options displayed as images. |
| [`Icon`](advanced-fields.md#icon-field) | `icon` | Icon picker, from Font Awesome or a custom icon set. |
| [`KeyValue`](advanced-fields.md#keyvalue-field) | `key_value` | Repeatable key and value pairs. |
| [`Link`](advanced-fields.md#link-field) | `link` | URL, link text and target, with the WordPress link picker. |
| [`GoogleMap`](advanced-fields.md#googlemap-field) | `map` | Location on a Google map. |
| [`OEmbed`](advanced-fields.md#oembed-field) | `oembed` | URL of an embeddable media, with a preview. |
| [`OpenStreetMap`](advanced-fields.md#openstreetmap-field) | `osm` | Location on an OpenStreetMap map. |
| [`Password`](advanced-fields.md#password-field) | `password` | Password input. |
| [`SelectAdvanced`](advanced-fields.md#selectadvanced-field) | `select_advanced` | Dropdown list with search (Select2). |
| [`Slider`](advanced-fields.md#slider-field) | `slider` | Numeric value chosen with a slider. |
| [`Switcher`](advanced-fields.md#switcher-field) | `switch` | On / off toggle. |
| [`TextList`](advanced-fields.md#textlist-field) | `text_list` | Several labelled text inputs saved as a list. |
| [`Timepicker`](advanced-fields.md#timepicker-field) | `time` | Time picker. |
| [`Wysiwyg`](advanced-fields.md#wysiwyg-field) | `wysiwyg` | Rich text with the WordPress editor. |
